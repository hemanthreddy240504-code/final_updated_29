## Project

## Main features
- Authentication: Register, Login, Logout, session expiry.
- Company CRUD: add, edit, delete, search and filter.
- Pipeline KPIs and analytics.
- Stage, partner, owner, industry and monthly charts.
- Stale-opportunity alert.
- Responsive UI for desktop and mobile.
- Light/Dark theme.

## Tech stack
Python, FastAPI, SQLAlchemy, SQLite/PostgreSQL, HTML, CSS, JavaScript, Chart.js.
